# Java Multithreaded Tetris

A simple Tetris game developed using Java 17 to demonstrate the concept of multithreading.

## Features

- Classic Tetris gameplay
- Falling and rotating blocks
- Keyboard controls
- Score and level tracking
- Automatic line clearing
- Pause and restart functionality
- Separate game and statistics tasks
- Thread monitoring

## Multithreading Concepts

This project demonstrates:

- Main Thread
- Game Thread
- Statistics Thread
- Scheduled Executor Service
- Periodic task execution
- Thread monitoring

## Technologies Used

- Java 17
- Java Swing
- ExecutorService
- ScheduledExecutorService

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java 17 is configured.
4. Open `Main.java`.
5. Run the `Main` class.

## Purpose

This project was developed as a practical demonstration of Java Multithreading.
